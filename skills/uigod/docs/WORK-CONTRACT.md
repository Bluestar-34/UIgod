# 作品与风格包统一标准

适用于库中的每个 styles/<id>/。库保存可复用的最终内容，制作过程留在实际项目或临时目录。既有网页包兼容原合同，不因缺少视频文件被判无效。

## 每个条目必须有

| 内容 | 唯一存放位置 | 要求 |
|---|---|---|
| 身份与索引 | style.json | id、名称、媒介、别名、状态、sources、deliverables；来源缺失写明，不编造 |
| AI 入口 | SKILL.md | 简短触发、读取顺序和迁移边界 |
| 风格与提示词 | DESIGN.md | 视觉规则、可改变量、反例和 Prompt Guide；不另建同内容提示词文件 |
| 来源与分析依据 | references/source-observations.md | 区分创作来源、视觉母版与迁移样例；注明用户提供/已读取/未核验 |
| 一张封面 | deliverables.cover 指定文件 | 使用真实预览截图，点击可进入预览 |
| 可用预览 | preview.html | 本地可打开；脚本与必要依赖可自包含或放 assets/ |
| 新内容验证 | examples/index.html | 新主题/内容的迁移示例；未完成则状态 draft，不装成已验证 |

gallery 与 catalog 使用 style.json 的文件指针，不根据文件名猜测。已有包允许原文件名，新增包优先 cover.png。保持一份权威文件，不为了统一名字再复制一份。

## 视频额外需要

- references/文案.md：已提供原作品时保存该作品最终制作文案；明确其来源。只有视觉参考且无文案时，在 source-observations 中标为未提供，不自动杜撰转写。
- examples/文案.md：当前迁移样例最终台词/屏幕文案；无配音明确说明。
- examples/transfer.mp4：已验证的可播放样片。正式片可提供稳定链接，别把大工程或多版导出都塞进库。
- examples/verification.json：检查结果、未验证项、批准状态。短样例验证不能替代正式片审批。
- references/frames/：只在分析确实依赖多帧证据时保留代表帧、时间索引和一张接触表。建议 6–12 帧，不收逐帧导出。

字幕需要时仅保留最终处理的一份，必须说明对应哪条音轨。没有真实配音就不伪造字幕对齐。必要配音/音乐可保留最终文件或指向项目的稳定路径，不保存每句音频和中间混音。

## 按需保留

assets/：预览必须的字体、图形及授权。references/code-patterns/：真实可复用代码；只有说明或空目录时不强制建立。用户原始创作提示词有独立研究价值时可在来源记录中指向它，别与通用制作提示词混为一谈。

## 不放什么

- 中间机器转写、原始错误字幕、重复 SRT/JSON/TXT 时间轴。
- 自动截取的所有核对图片、多份桌面/手机截图、过期首帧及重复封面。
- node_modules、缓存、日志、账号配置、密钥、下载任务目录及整套旧制作工程。
- 多版成片、未标注用途的参考素材、无法说明作用的小字/装饰模板。
- 把“风格说明”“使用说明”“提示词”“检查清单”各写一份却重复同一内容。

过程验证截图进入系统临时目录，不默认提交。清理现有文件前检查是否被页面或文档引用；需要的改为单一文件指针后再清理。

## 来源记录规则

sources 中每项写 role、url 或 path、provided_by、verification、use_for。角色推荐 creative-origin（选题/文案原参考）、visual-reference（实际审美证据）、transfer-example（新主题迁移）。链接不能访问时记录 user-provided/unverified，不能声称已看过其内容。

用户只提供“创作源地址”时记录为来源；没有明确视觉授权时不自动将其视频、封面、图片纳入视觉母版。后续禁止参考视觉的要求仍然有效。

## 库与生产项目的边界

完整生产项目另存：最终文案、分镜/场景数据、真实配音、最终字幕、必要素材、可重建源码、最终 MP4 和制作记录。UIgod 只收录上面必要的风格规则与预览，原工程地址记录在来源中。不得为了整理库而删改原作品工程。


## 全量外部参考的轻量收录

外部清单可放 collections/<collection-id>/，完整保留上游 README、LICENSE、原始数据与逐条提示词，并附导入版本与文件哈希。每条进入 catalog，kind=external-reference、status=imported-unverified，保留作者、原帖、远程海报和预览链接、prompt_partial。

外部参考尚未提炼，不强制伪造 DESIGN.md、SKILL.md 或本地样片。用户选为精选也不自动变成已验证风格；需要进一步分析再建正式风格包。重复提示词对应不同作品时保留各自记录，不用去重抹掉作者或效果差异。

curation.json 只记录用户精选，默认 default_view=all。上游 highlighted、热度、模型推荐均不算用户精选。网页“加入精选/取消精选”是用户操作，保存在本浏览器，可导出 curation.json 保存到仓库；浏览器不会静默改写磁盘文件。
